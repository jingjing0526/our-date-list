🔥 设置实时同步
用 Supabase 免费服务——设置一次，之后永久自动同步，不需要发链接 💕
📋 三步搞定（约 3 分钟）：

① 打开 supabase.com → 用 Google 登录 → 「New project」→ 随便起个名字 → 创建（等约 1 分钟）

② 左侧点「SQL Editor」→「New query」→ 把下面这段代码粘贴进去 → 点「RUN ▶」
create table couple_sync (room_id text primary key, todos jsonb default '[]'::jsonb, trips jsonb default '[]'::jsonb); alter table couple_sync enable row level security; create policy "open" on couple_sync for all using (true) with check (true); alter publication supabase_realtime add table couple_sync; ③ 左侧点「⚙️ Settings」→「API」→ 复制 Project URL 和 anon public key，粘贴到下方
🔗 Project URL
🔑 Anon Key (public)
✅ 实时同步已开启 🎉
你在电脑上加的内容会立刻出现在手机上，反过来也是 💕
